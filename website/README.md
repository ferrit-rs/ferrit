# Project showcase website

Deployed site: https://template-website-personal-blog.vercel.app/

## Run the project

```bash
pnpm install
pnpm run dev
```

## Template configuration

Client-wide identity, links, author details, and profile stats live in
`lib/site.ts`. Project-specific content, metrics, steps, and system layers live in
`lib/project.ts`. Replace placeholder `.webp` assets in `public/images` when
customizing the template.
